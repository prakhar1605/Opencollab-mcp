# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

## Reporting a Vulnerability

Report vulnerabilities privately using GitHub's **Security** tab and **Report a vulnerability**. Do not report vulnerabilities in public issues.

Examples of in-scope reports include token leakage, path injection into API requests, and HTTP transport issues.

An acknowledgement is expected within a few days, followed by a fix or an explanation.
